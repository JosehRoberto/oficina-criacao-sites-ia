## Prompt 3 — Página inicial

```text
Preencha a página inicial com uma área de destaque, uma apresentação do projeto, uma seção de trilhas de aprendizagem, uma seção de recursos, uma área para portfólio e um rodapé com contato.
Use português do Brasil.
```

## Prompt 2 — Estrutura inicial

```text
Agora crie APENAS a estrutura inicial do projeto, usando os arquivos index.html, style.css e script.js.
Use HTML5, CSS e JavaScript puro. Não instale frameworks nem dependências externas.
No index.html, crie um menu de navegação (header) no topo e estas seções, nesta ordem: área de destaque (hero), apresentação do projeto, trilhas de aprendizagem, recursos, portfólio, contato e rodapé.
Deixe cada seção só com o título e um marcador; sem conteúdo real e sem funcionalidades.
No style.css, inclua apenas uma base mínima: tipografia legível e um espaçamento simples entre as seções. O restante vem depois.
Não preencha textos, dados, busca, filtros nem progresso ainda.
```
