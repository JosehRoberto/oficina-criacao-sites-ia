# Conteúdo programático da oficina

## Ementa

Introdução ao desenvolvimento de sites com apoio de inteligência artificial, com foco em planejamento, prompting, construção guiada de páginas, estruturação de conteúdo, ajustes visuais, versionamento e publicação de um projeto web estático.

## Objetivo geral

Capacitar os participantes a compreender e aplicar uma dinâmica básica de criação de sites com apoio de ferramentas de IA, utilizando um projeto-padrão como base para futuras adaptações em seus produtos educacionais e contextos profissionais.

## Objetivos específicos

- Entender o papel da IA no desenvolvimento inicial de sites.
- Utilizar prompts para orientar a criação de uma interface web.
- Reconhecer a estrutura essencial de um projeto HTML/CSS/JavaScript.
- Ajustar visualmente um site criado com apoio de IA.
- Organizar os arquivos do projeto.
- Realizar versionamento básico com Git.
- Publicar o site no GitHub Pages.

## Conteúdos

### Bloco 1 — Contextualização

- O que é desenvolver sites com apoio de IA.
- Diferença entre gerar conteúdo e estruturar um projeto.
- Limites e cuidados no uso pedagógico das ferramentas.

### Bloco 2 — Preparação do projeto

- Estrutura da pasta do projeto.
- Uso do OpenCode como interface de trabalho.
- Definição do projeto-base.

### Bloco 3 — Construção guiada

- Geração inicial do site.
- Criação de seções e menu.
- Inserção de trilhas, portfólio, contato e rodapé.

### Bloco 4 — Refinamento

- Ajustes de layout.
- Cores e tipografia.
- Melhorias de responsividade.
- Revisão do conteúdo textual.

### Bloco 5 — Recursos interativos simples

- Indicador de progresso salvo localmente no navegador.
- Área de anotações pessoais salva localmente.
- Interações básicas com JavaScript, sem back-end.

### Bloco 6 — Personalização

- Adaptação do projeto-base ao contexto individual.
- Troca de textos, seções e identidade visual.
- Definição de próximos passos para expansão futura.

### Bloco 7 — Publicação

- Criação do repositório.
- Envio dos arquivos ao GitHub.
- Ativação do GitHub Pages.

## Produto esperado

Um site estático funcional, publicado online, com estrutura inicial suficiente para servir de base à evolução futura do projeto pessoal de cada aluno.
