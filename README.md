# Desenvolvimento de Sites com Inteligência Artificial

Materiais de apoio da oficina **Desenvolvimento de Sites com Inteligência Artificial**, destinada aos alunos do PPGCIMES/NITAE/UFPA.

## Preparação do ambiente

Antes da oficina, leia e siga **somente** o [guia de instalação para Windows](02-instalacao/guia-aluno-windows.md).

Os demais materiais serão liberados durante a oficina, de forma sincronizada.

## Cuidados

Não envie senhas, tokens ou chaves de API em grupos ou repositórios. Consulte o ministrante em caso de dúvidas.
