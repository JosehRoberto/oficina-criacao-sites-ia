# Planejamento da oficina

## Título

**Desenvolvimento de Sites com Inteligência Artificial**

## Público

Alunos do mestrado do PPGCIMES/NITAE/UFPA, com perfis variados e predominância de usuários iniciantes em terminal, desenvolvimento web e configuração de ferramentas de linha de comando.

## Duração

Quinta-feira, 22/10/2026, das 08h30 às 12h00.

## Premissas pedagógicas

- A oficina é introdutória e prática.
- O foco será a compreensão da dinâmica de criação de sites com apoio de IA.
- Será desenvolvido um único projeto-base, comum a todos, para reduzir dispersão e facilitar o acompanhamento.
- A personalização individual ocorrerá ao final, após a compreensão do projeto padrão.
- O ambiente técnico deverá ser o mais simples possível para a turma, priorizando Windows nativo em vez de WSL2.

## Justificativa do projeto único

As respostas dos alunos mostram interesses diversos: produto educacional, trilhas de aprendizagem, organização de aulas, portfólios, cursos de idiomas, mural colaborativo, progresso, certificados e até aplicativos. Em uma oficina curta, a melhor estratégia é trabalhar um **projeto único de site-modelo**, capaz de demonstrar recursos comuns que depois podem ser adaptados para produtos educacionais específicos.

## Projeto-base sugerido

**Portal de Trilhas de Aprendizagem**

O projeto deverá conter:

- página inicial com proposta do projeto;
- menu de navegação;
- seção sobre o projeto/produto educacional;
- seção de trilhas ou módulos;
- área para links de aulas, vídeos e materiais;
- galeria ou portfólio;
- formulário visual de contato;
- seção de registro ou anotações locais simuladas;
- indicador de progresso salvo localmente no navegador;
- rodapé com autoria e informações institucionais.

## Delimitação do escopo

Serão tratados como recursos demonstráveis nesta oficina:

- HTML, CSS e JavaScript básicos;
- organização de páginas e componentes;
- estrutura de navegação;
- responsividade inicial;
- produção guiada por prompts no OpenCode;
- versionamento com Git;
- publicação com GitHub Pages.

Serão tratados como **expansões futuras**:

- autenticação de usuários;
- banco de dados real;
- mural multiusuário real;
- certificados automáticos com persistência;
- sistema real de progresso com backend;
- aplicativos móveis nativos.

## Ambiente técnico adotado

- Windows 10 e Windows 11 como foco principal.
- Instalação nativa de VS Code, Git, Node.js e OpenCode.
- Uso preferencial de provedores de IA com acesso gratuito disponível.
- Uso de 9Router apenas como camada ampliada, não obrigatória para participação.

## Estratégia de contingência

- Se o 9Router falhar, o aluno segue com conexão direta do OpenCode ao provedor.
- Se a conta gratuita de um provedor falhar, utilizar uma segunda opção previamente preparada.
- Se o notebook não estiver funcional, o aluno poderá acompanhar em dupla.
- Se o aluno tiver apenas iPad, poderá acompanhar de forma adaptada com interfaces web, mas não reproduzirá toda a trilha técnica local.

## Resultados esperados

Ao final da oficina, espera-se que o aluno consiga:

- compreender a lógica básica de desenvolvimento de um site com IA;
- utilizar prompts para orientar a construção de um projeto web;
- identificar componentes essenciais de uma página;
- revisar e ajustar arquivos do projeto;
- publicar o projeto em repositório GitHub;
- ativar o GitHub Pages para exibir o site final.
